# IPTVSubs8K website

Next.js 15 site for iptv-usa8k.com. Pages are static and generated from Markdown.

## Commands

```bash
npm install
npm run dev
npm run quality
npm run build
npm run typecheck
npm start
npm run qa
```

`npm run build` runs the quality gate first. `npm run qa` needs the production server running (`BASE=http://localhost:3000` by default).

## Where things live

| Path | Purpose |
| --- | --- |
| `content/business.json` | Real business facts. Leave a field null until the owner confirms it. |
| `content/pages/*.md` | One file per page: metadata, FAQs and related links in the frontmatter, body in Markdown. |
| `seo/keyword-map.json` | Each researched keyword and the one URL that owns it. |
| `seo/indexability.json` | Generated by the quality gate. Controls robots tags and the sitemap. |
| `seo/quality-report.json` | Generated. Full quality gate results. |
| `seo/qa-report.json` | Generated. Results of the last QA crawl. |
| `public/img` | Images used by the site, selected from `images/`. |

## Adding a page

1. Check `seo/keyword-map.json`. Add a page only for an intent no existing page covers, and move its keywords to the new URL.
2. Add a Markdown file in `content/pages`, using a nearby page as the frontmatter template.
3. Link to it from at least one related page.
4. Run `npm run quality`. Pages with any failure stay `noindex` and out of the sitemap.

## Going live

These must be filled in `content/business.json` before the gated pages can be indexed: contact channels, `checkoutMethod`, `trial`, `refundPolicy`, `legalEntity` and `reseller`. To receive contact form messages, set `CONTACT_WEBHOOK_URL` on the host.

Do not publish channel or network names until `contentRightsConfirmed` is true.
